# PL-300 — Power BI Data Analyst
Banque de révision interactive pour la **certification Microsoft PL-300 – Power BI Data Analyst**

## Fonctionnalités
*  Fiches de révision
*  Quiz interactifs
*  Entraînement question par question
*  Questions et réponses aléatoires
*  Calcul du score
*  Révision des erreurs
*  Interface adaptée aux smartphones
*  Utilisable directement depuis un navigateur

## Objectif
Construire progressivement une banque de questions complète et de qualité pour s'entraîner à la certification PL-300.
Le projet sera enrichi progressivement avec plusieurs banques de questions couvrant notamment :
* Power BI
* Modélisation des données
* Power Query
* DAX
* Visualisation
* Power BI Service
* Microsoft Fabric
* Copilot dans Power BI
* Analyse et gestion des données

## Utilisation
Le projet est conçu pour être utilisé directement depuis un navigateur grâce à **GitHub Pages**.
Aucune installation particulière n'est nécessaire.
